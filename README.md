# CMoss
CMoss is the [Moss Framework](https://github.com/TxbiG/MossFramework) binding written in C. Rendering and physics are primarily written in C++ in the backend.

## Documentation

Comprehensive documentation is available in the [`docs/`](./docs) directory:

* Architecture overview
* Rendering system design
* Physics system design
* Audio pipeline
* Input system
* Networking model
* Platform backend architecture
* Performance guidelines

- [API cheatsheet](docs/API_Cheatsheet.md)

- C++ 17
